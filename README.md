🐉 Spyro Guide App

Aplicación Android desarrollada en Kotlin basada en el videojuego
clásico Spyro the Dragon, que ofrece una guía interactiva con navegación
por mundos, personajes y coleccionables.

📱 Características principales

-   Navegación por secciones (Personajes, Mundos, Coleccionables)
-   Guía interactiva paso a paso con animaciones
-   Efectos de sonido en la interacción
-   Resumen final de progreso de la guía
-   Persistencia de estado con SharedPreferences
-   Uso de múltiples layouts con includes
-   Animaciones con ObjectAnimator

🛠️ Tecnologías utilizadas

-   Kotlin
-   Android SDK
-   XML (Layouts tradicionales)
-   ViewBinding
-   Navigation Component
-   SharedPreferences
-   SoundPool
-   ObjectAnimator

🚀 Cómo ejecutar el proyecto

1.  Clona el repositorio: git clone
    https://github.com/JpedrosaPerez/Spyro.git

2.  Abre el proyecto en Android Studio

3.  Ejecuta en emulador o dispositivo físico
